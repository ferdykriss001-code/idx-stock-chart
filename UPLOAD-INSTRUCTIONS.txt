UPLOAD SEKALI — IDX STOCK CHART

1. Upload SELURUH ISI folder ini ke root repository GitHub (branch main).
2. Jangan upload ZIP-nya; ekstrak lebih dahulu.
3. Pastikan file berikut terlihat:
   .github/workflows/refresh-market-data.yml
   .github/workflows/refresh-intraday-data.yml
   scripts/update_market.py
   index.html
4. Buka Actions lalu jalankan "Refresh IDX daily candles".
5. Setelah hijau, jalankan "Refresh IDX 5-minute candles".
6. Tunggu deployment GitHub Pages, lalu Ctrl+Shift+R.

Daftar: 50 saham market cap dari CSV + BKSL, KETR, PTBA, NETV, PTRO, ITMG + JGLE.
Jika Yahoo tidak menyediakan sebuah ticker pada saat refresh, file lama yang valid dipertahankan dan alasan gagal dicatat di data/refresh-status-*.json.
